PASSAGGI DANZA - FRONTEND GITHUB

Questa versione NON modifica Google Apps Script e NON sposta i dati.
GitHub Pages serve solo come contenitore installabile su iPhone con icona personalizzata.
La web app Google esistente viene caricata dentro la pagina GitHub tramite iframe.

FILE DA TENERE NEL REPOSITORY:
- index.html
- icon.png

AGGIORNAMENTO DEL REPOSITORY ESISTENTE:
1. Apri il repository GitHub passaggi-danza.
2. Sostituisci il vecchio index.html con quello di questo pacchetto.
3. Lascia/aggiorna icon.png con quello di questo pacchetto.
4. Commit changes.
5. Attendi che GitHub Pages pubblichi l'aggiornamento.
6. Apri la pagina GitHub Pages in Safari su iPhone.
7. Elimina dalla Home eventuali vecchie icone di Passaggi Danza.
8. Safari > Condividi > Aggiungi alla schermata Home.

IMPORTANTE:
- Non modificare Code.gs.
- Non rilanciare setupDemoWeeks.
- Il vecchio link Google Apps Script continua a funzionare normalmente.
